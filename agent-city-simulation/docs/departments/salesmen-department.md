# Salesmen Department - The Go-To-Market Team
*"Where certified products become launched, revenue-generating businesses."*

## Core Concept
Receives quality-certified product from Testers → Launches to market → Drives user acquisition

## Launch Workflow (2-4 weeks)

**Pre-Launch (Week -1)**:
- Create landing page with waitlist
- Build buzz on Twitter, Reddit
- Prepare ProductHunt submission
- Set up analytics (Google Analytics, Mixpanel)

**Launch Day**:
- Submit to ProductHunt (aim for top 3)
- Post on HackerNews
- Email waitlist
- Social media blitz
- Monitor real-time signups

**Post-Launch (Week 1-4)**:
- A/B test messaging
- Iterate on onboarding flow
- Respond to user feedback
- Monitor metrics daily

## Success Metrics
- Week 1: 100+ signups
- Week 4: 500+ signups
- Retention: 40%+ week-2 retention
- ProductHunt: Top 5 product of the day
- User rating: 4.0+/5.0 stars

## Recursive Learning

**Pattern Learned**: "ProductHunt launches get 3x more signups than HackerNews for consumer apps"

**Feedback to Idea Factory**:
- "Users love feature X" → Scout for similar ideas
- "Users complain about missing feature Y" → New idea seed

**Outcome Tracking**:
```yaml

```

## Integration with Other Departments

**Post-Launch Insights → Idea Factory**:
- User feature requests become new idea seeds
- Market validation data feeds back to scouts

**Revenue Generation → Stockbrokers**:
- Once product hits $5k revenue → Activate Stockbrokers
- Profits reinvested into scaling or new products

**Key Insight**: Salesmen close the loop - real market feedback validates entire pipeline.
